dau_core.temporal¶

Golden models for the temporal-finance hero workflow.

The fused workflow this file is the CPU reference for:

quotes ─┐

├─> backward as-of ─> midpoint/spread/sign ─┐

trades ─┘ ├─> time/vol/$ bars

└─> rolling features

Everything here operates on the encoded integer domain the hardware sees — symbol ids are int32 dictionary codes, timestamps are int64, prices/sizes are int64 fixed-point (the host quantizes at a chosen scale before staging, exactly as dau_polars.ohlcv does with its micro-unit SCALE). The models are therefore scale-agnostic integer arithmetic: a caller that quantizes price and size at scales Sp and Ss gets dollar volume in Sp*Ss units and must express dollar-bar thresholds in the same units. Division is deferred (Q100 discipline): bars and rolling windows emit exact integer accumulators (sum / sum-of-squares / count) and the host divides once, so every value on the wire is exact.

State is bounded and per-symbol: the as-of tile holds one current quote per symbol partition; a bar tile holds one open bar; a rolling tile holds one window. The pre-sort precondition (both streams ordered by (symbol_id, time)) is the same one the sorted-scan tiles already require — the host sorts, or the range-partitioner + sorter path does.

These are semantic references, ahead of the HDL. The int64 timestamp / sum tiles and the as-of / windowed-stat tiles byte-compare against them.

dau_core.temporal.asof_backward(trades: collections.abc.Iterable[TradeRow], quotes: collections.abc.Iterable[QuoteRow], *, tolerance: int | None = None) → list[MarketRow | None][source]¶

Backward as-of join: each trade attached to the most recent quote for the same symbol whose quote_time <= trade_time (and, when tolerance is set, trade_time - quote_time <= tolerance). Emits one entry per input trade, in input order — a matched (symbol_id, time, price, size, bid, ask) market row, or None when no quote qualifies (the miss is a typed residue; matched_rows() drops them).

Matches polars.DataFrame.join_asof(strategy="backward", by="symbol", tolerance=...): on equal timestamps the last qualifying quote wins. Both streams must be pre-sorted by (symbol_id, time). The tile holds one current quote per symbol partition and advances it monotonically — bounded state, one pass.

dau_core.temporal.rolling_moments(values: collections.abc.Iterable[tuple[int, int]], *, window: int) → list[RollingMoment | None][source]¶

Per-symbol rolling (count, sum, sum_of_squares) over the last window values — the deferred-division form of rolling mean/variance.

REFUSES a window whose sum of squares leaves a signed 64-bit accumulator. That is the tile’s arithmetic precondition, and it binds inside the int32 domain: (2**31-1)**2 is already 2**61, so a full-range int32 column overflows sum_sq from window 3. The tile cannot check it — it sees one row at a time and has no bound to compare against — and it wraps silently into a wrong variance rather than erroring. Python integers do not wrap, so a golden that computed the exact value would DISAGREE with the hardware over exactly the inputs the contract excludes, and the bench comparing the two would be the only thing that ever noticed. Raising instead keeps the reference and the datapath from ever quietly parting company: inside the precondition they are equal, and outside it neither claims an answer.

The proof properly lives further upstream — dau-polars refuses to route a rolling scan whose value column declares no magnitude_bits — so this is a backstop for a direct caller, not the primary check.

dau_core.temporal.moment_mean(moment: RollingMoment) → float[source]¶

Mean from a rolling moment.

dau_core.temporal.moment_var(moment: RollingMoment, *, ddof: int = 1) → float[source]¶

Variance from a rolling moment (ddof=1 sample variance, matching polars.rolling_var). Raises on an under-determined window.

The numerator count*sum_sq - sum*sum is formed in exact integers before the single float divide — dividing sum*sum first (float) would cancel the variance away at fixed-point magnitudes (e.g. three consecutive values near 1e9).

dau_core.temporal.moment_std(moment: RollingMoment, *, ddof: int = 1) → float[source]¶

Sample standard deviation from a rolling moment.

The root of moment_var(), and deliberately defined in terms of it rather than independently: polars’ rolling_std is the root of its rolling_var, so any other formulation would disagree with the reference in the last place for no benefit.

On device this is where the divide and sqrt tiles land – variance divides before it roots – which is why the numerator stays exact integers right up to the single divide.

dau_core.temporal.ewma(values: collections.abc.Iterable[tuple[int, int]], *, alpha: float) → list[float][source]¶

Per-symbol exponentially weighted moving average, non-adjusted recursion (e[0] = x[0]; e[i] = alpha*x[i] + (1-alpha)*e[i-1]) — matches pl.col(x).ewm_mean(alpha=alpha, adjust=False).over("symbol"). Float: the reference real-valued semantics the fixed-point tile approximates under its declared error budget.

dau_core.temporal.deltas(values: collections.abc.Iterable[tuple[int, int]]) → list[int | None][source]¶

Per-symbol first difference (value[i] - value[i-1]; None for the first row of each symbol) — matches pl.col(x).diff().over("symbol").

class dau_core.temporal.MarketStream[source]¶

A deterministic (seeded) quote/trade fixture in the encoded domain, both streams sorted by (symbol_id, time).

quotes: tuple[QuoteRow, ...]¶

dau_core.temporal.generate_market_stream(*, seed: int, num_symbols: int = 4, quotes_per_symbol: int = 24, trades_per_symbol: int = 40, price_scale: int = 1000000) → MarketStream[source]¶

Generate a deterministic quote/trade fixture: per symbol, a random-walk two-sided quote (micro-dollar prices) and interleaved trades in integer share sizes priced near the prevailing midpoint — so dollar_volume accumulators stay comfortably in int64. Same seed ⇒ byte-identical output (replay determinism). Uses only the stdlib random — zero-dependency, like the rest of dau-core.

Both paths are exercised by construction: one trade per symbol is placed just before that symbol’s first quote, so asof_backward() always produces at least one miss as well as matches.

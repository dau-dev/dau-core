class dau_core.registers.HandleTableControlFlag[source]¶

Bases: enum.IntFlag

The WRITE bits of HandleTableRegisterOffset.CONTROL: which of the staged entry’s two commits the write performs. Both are one-cycle pulses, so they always read back zero – CONTROL reads report the resolution state instead.

Here rather than in the host, for the same reason the offsets are: a bit position a programmer carries in their head is how a free ends up installing. A host stages one commit or the other; the table resolves the collision in free’s favour, which is a safety net, not a sequence.

Initialize self. See help(type(self)) for accurate signature.

FREE = 2¶
class dau_core.registers.HandleFaultCode[source]¶

Bases: enum.IntEnum

LAST_ERROR codes a shell reports for a job it REFUSED to start on a handle. A refused job never starts the reader, so it reads nothing at all – these mean the datapath is untouched, not that it produced garbage.

They sit at the top of the code space, below the shell’s own 0xFE length-gate fault, because that space is the shell’s: a tile’s error codes are small and per-core (dau_core.operators), and a fault that refuses the job outright is not one of them.

Initialize self. See help(type(self)) for accurate signature.

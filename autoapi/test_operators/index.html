test_operators.test_divide_at_zero_fractional_bits_is_python_floor_division() → None¶

The bridge a col_a // col_b lowering rests on.

polars integer // floors, and so does this tile at FRACTIONAL_BITS=0 – (A << 0) // B is just A // B. That equivalence is what lets a column-by-column floor divide lower onto the divide tile with no host correction, so it is pinned rather than left as a reading of the code.

The negative cases are the ones that matter: a tile truncating toward zero would agree on every positive pair and disagree on half the rest.

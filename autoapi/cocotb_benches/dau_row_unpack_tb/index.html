async cocotb_benches.dau_row_unpack_tb._run_bypass(dut, words, *, ready_pattern=(1,)) → list[int]¶

Drive a bypass batch (cfg_bypass must already be 1) and collect the forwarded stream. Bypass is 1:1 word-for-word (no widening), so the output is exactly len(words) words; _send_words/_collect_output already assert hold-stability, last placement, and silent-success quiescence.

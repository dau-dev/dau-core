dau_core
========

.. py:module:: dau_core

.. autoapi-nested-parse::

   dau-core: the tile palette, the device contracts and the goldens.

   Exports load on first use (:mod:`dau_core._lazy`). Importing this package
   must not import ccflow and its stack, because hydra's searchpath plugin
   imports ``dau_core.config`` to discover what is installed, and discovery
   wants none of these names.

Package Contents

.. py:function:: lazy_exports(package: str, exports: dict[str, tuple[str, ...]]) -> tuple[collections.abc.Callable[[str], object], list[str]]

   A module ``__getattr__`` and ``__all__`` for ``{submodule: names}``.

   Returns both so the two cannot disagree: a name exported by nothing is
   not reachable, and a name declared here and missing from its submodule
   raises on first access rather than at import, which a guard test is what
   turns back into an import-time error.

## Pre-requisites

You need Python >=3.10 on your machine to install `dau-core`.

## Install with `pip`

```bash
pip install dau-core
```

## Install with `conda`

```bash
conda install dau-core --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `dau-core` from source](Build-from-Source).
